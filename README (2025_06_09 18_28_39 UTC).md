# Password Manager

A simple personal password manager for Windows with a graphical interface (Tkinter), encrypted local storage, and master password protection.

## Features
- Add, view, and search passwords
- All data is encrypted with a master password
- User-friendly GUI
- Local encrypted file storage
- Exportable as a standalone .exe (via PyInstaller)

## How to run
1. Install requirements: `pip install -r requirements.txt`
2. Run: `python main.py`

## How to build .exe
1. Install PyInstaller: `pip install pyinstaller`
2. Build: `pyinstaller --onefile --noconsole main.py`

---
**Warning:** Never share your master password or encrypted file with others.
